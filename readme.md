# Лабораторная работа №1: Сбалансированное бинарное дерево поиска (АВЛ-дерево)

Проект представляет собой реализацию абстрактного типа данных «Бинарное дерево поиска» с автоматической балансировкой (АВЛ-дерево) на языке C++. Программа оснащена консольным пользовательским интерфейсом (TUI) на базе библиотеки FTXUI и покрыта модульными тестами Google Test.

# Реализованный функционал

**Структуры данных и алгоритмы (`avl_tree.h`):**
* **Управление памятью:** Дерево реализовано на динамических структурах с использованием умных указателей `std::shared_ptr` для безопасного управления памятью и предотвращения утечек.
* **Базовые операции:** Реализованы вставка (`add`), поиск (`find`), получение значения (`get`) и удаление узлов (`remove`).
* **Балансировка:** Автоматическое поддержание свойств АВЛ-дерева (малые и большие вращения) при вставке и удалении узлов.
* **Функциональные операции (ФВП):**
    * `map`: Построение нового дерева поэлементным преобразованием (поддерживается смена типа данных).
    * `where`: Фильтрация узлов по заданному предикату (условию).
    * `reduce`: Свертка элементов дерева в единое значение по заданному правилу.
* **Дополнительные операции:**
    * `subtree`: Извлечение поддерева по заданному ключу (корню).
    * `to_string` / `from_string`: Сохранение дерева в строку и чтение из строки (по фиксированному симметричному обходу in-order).

**Пользовательский интерфейс (`ui.cpp`):**
* Интерактивный терминальный интерфейс (TUI) с использованием функционала библиотеки FTXUI.
* Поддержка деревьев трех типов: `int`, `double`, `std::string` (реализовано через `std::variant`).
* Наглядная псевдографическая визуализация структуры дерева в реальном времени.
* Интерактивное меню для вызова всех функций дерева (`add`, `remove`, `map`, `where`, `reduce`, `subtree`) с возможностью выбора лямбда-выражений из заранее подготовленного списка.

**Тестирование (`avl_tree_tests.cpp`):**
* Полное покрытие базовых алгоритмов, балансировки, всех поворотов и функциональных методов с помощью фреймворка Google Test.
